Kanun Sathi: Nepal's Law, With Sources

Ask a legal question in Nepali or English and get an answer grounded in the actual law, with the source cited.

Ankit Pokhrel
1 min read·2026·source

The problem

Many young people in Nepal have no reliable way to check what the law actually says. They pick it up from social media or from elders answering from experience. Kanun Sathi answers in plain language from the Constitution, criminal law, family law and social regulations, and every answer names the document and article it came from, so people can check it themselves.

What I built

  • Built on Morphik, an open-source RAG framework, configured for Nepali.
  • Gemini 2.5 Flash writes the answers; we picked it because it handled Nepali better.
  • Embeddings run locally with Ollama's nomic-embed-text (768 dimensions), stored in PostgreSQL with pgvector.
  • Documents are chunked at 2,000 with 200 overlap; the original 6,000 kept overflowing the local model's context.
  • Prompts that enforce citations, so every answer points back to page-level sources in the law.
  • Ingestion runs in background workers (Redis + ARQ), so uploading a big document doesn't block the API.
  • A React + TypeScript frontend, and the whole stack (FastAPI, PostgreSQL/pgvector, Redis, Ollama) containerised with Docker Compose.
  • role RAG pipeline, backend, frontend and Docker setup (team of 4)
  • timeline started at my first hackathon; this version Jan - Feb 2026
